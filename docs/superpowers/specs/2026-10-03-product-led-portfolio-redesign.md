# 产品能力导向的个人网站改版设计

## 目标

将 `zhangshuhui.com` 从信息完整的网页简历，重构为能够在几十秒内证明产品能力的个人作品。招聘者首先看到产品、决策和结果，而不是个人履历、长篇说明或简历下载入口。

首要印象：张树蕙能够把复杂业务抽象成规则，推进成真正上线运行的产品。

## 设计原则

1. 产品先于个人资料：首屏直接展示 Collab 界面和产品定位，不使用证件照卡片作为主视觉。
2. 决策先于过程：只保留能够体现判断力的关键取舍，删除流水账式工作步骤。
3. 画面先于文字：用真实产品截图、状态流程和前后对比承担主要叙事。
4. 结果必须可核验：展示已有证据，同时明确样本和统计边界，不虚构商业结果。
5. 渐进式披露：首页负责建立判断；案例页负责证明；深入细节通过折叠区域按需展开。
6. 网站不是简历分发页：移除全部简历下载入口，联系方式降为页面末尾的次要行动。

## 首页结构

### 1. 首屏

- 主标题：`复杂业务，我负责把它做成产品。`
- 辅助说明：`AI 产品经理。主导业务建模、产品设计与上线交付。`
- 唯一主行动：查看 Collab 案例。
- 主视觉：Collab 产品界面组合，而不是个人信息卡。
- 保留姓名与岗位，不展示学历、年限和简历下载。

### 2. 旗舰产品：Collab

Collab 占首页主要篇幅，使用大幅界面和最少文字建立完整证据链：

- 结果：3 个真实活动、50+ 确认记录、近期样本周期约缩短 93%。
- 挑战：跨 Telegram、WhatsApp、邮件和社媒私信的协作无法追踪。
- 三个核心决策：
  1. 将跨渠道协作抽象为统一状态机；
  2. 合作条件变化后必须通知并重新确认；
  3. AI 辅助分类和提取，但不决定合作资格、付款与争议。
- 行动：查看完整案例。

### 3. 两个补充能力证明

- Creator Intelligence：强调需求结构化、候选发现、可解释匹配和人工复核，证明 AI 产品化能力。
- Airacle Website：强调从模糊需求到视觉选型、工程交付和商业复盘，证明 0→1 推进能力。
- 两个项目使用横向视觉卡片，各自仅保留一个结论、一组证据和一个入口。

### 4. 结尾

- 一句工作原则：`先把真实业务跑通，再把 AI 放进最有价值的位置。`
- 一个联系入口：邮箱。
- 可小尺寸展示个人照片，但不得抢占产品视觉层级。

## 首页删除项

- 全部简历下载入口及简历 PDF 对外链接；
- 首屏证件照与学历、年限信息卡；
- 独立的四宫格方法论；
- 长篇个人介绍、教育经历与工作时间线；
- 重复解释“真实、边界、负责范围”的段落；
- 与核心案例重复的项目说明。

源仓库可暂时保留简历文件，但不得从任何公开页面或站点地图链接到它。若确认外部没有依赖，可在实现阶段一并删除。

## 案例页结构

三个案例统一为五段：

1. 挑战：一句事实和一张关键画面；
2. 我的判断：说明问题本质，而不是复述背景；
3. 产品决策：展示 2 至 4 个取舍；
4. 产品呈现：真实界面、流程或前后对比；
5. 结果与边界：数字、样本范围和下一步。

每个可见段落控制在一屏内。辅助背景、统计口径、职责边界和复盘细节进入原生 `details` 折叠区域，默认不展开但保持可访问。

## 视觉系统

- 风格：高端软件产品发布页与编辑式作品集的结合。
- 基础：暖白背景、近黑文字、电蓝作为唯一主强调色；酸绿色仅保留给结果或状态信号。
- 字体：超大中文展示标题、紧凑标签、清晰正文；避免整页相同字号与密度。
- 布局：大图、错位网格、宽幅产品舞台；减少重复卡片和边框。
- 动效：仅使用滚动进入、界面轻微景深和交互反馈，尊重 `prefers-reduced-motion`。
- 响应式：移动端优先展示结论、数据与主画面；不得出现横向滚动或依赖悬停的信息。

## 交互与导航

- 桌面导航只保留“产品”和“联系”。
- 移动端保留 44px 以上点击区域和明确的菜单状态。
- 首页至三个案例均可深链接。
- 案例页提供返回作品和相邻案例导航。
- 邮件为唯一转化动作；不设置下载简历按钮。

## 技术范围

- 继续使用当前静态 HTML、CSS 和少量 JavaScript，不引入框架和构建依赖。
- 优先复用已有真实截图，补充 CSS 生成的流程视觉，不制造虚假产品界面。
- 图片声明尺寸并延迟加载非首屏资源。
- 保留可访问性、SEO、404、robots 和 sitemap。
- 更新站点验证脚本，禁止任何页面出现“下载简历”及公开简历链接。

## 验收标准

1. 首屏不出现简历下载、学历时间线或大面积个人介绍。
2. 无需滚动即可理解候选人的定位，并看到真实产品画面。
3. 首页在 60 秒内可以回答：做了什么产品、解决了什么问题、作出了什么关键决策、产生了什么结果。
4. Collab 明显是主案例，另外两个项目只承担补充证明作用。
5. 每个案例的核心叙事最多五段，长背景默认折叠。
6. 全站不存在公开可点击的简历下载入口。
7. 桌面与 390px 移动端无横向溢出，键盘导航和焦点状态完整。
8. 所有页面、图片、邮件链接、404、robots 和 sitemap 验证通过。
9. 公网部署后逐页返回 200，并确认新版标题与案例入口可见。
